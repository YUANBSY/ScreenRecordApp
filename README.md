# 熄屏录像APK - 使用说明

## 📱 应用简介

这是一个Android应用，可以在华为nova7等Android手机上实现熄屏录像功能。

### ✨ 主要功能

- **熄屏录像**：屏幕熄灭后继续录像
- **自动保存**：视频自动保存到手机相册
- **高清录制**：支持1080p高清视频
- **声音录制**：同时录制画面和声音
- **计时显示**：实时显示录像时长

## 🔧 编译和安装步骤

### 方法一：使用Android Studio（推荐）

#### 1. 安装Android Studio

1. 访问官网下载：https://developer.android.com/studio
2. 下载Windows版本安装包
3. 运行安装程序，按照提示完成安装
4. 首次启动时，Android Studio会自动下载必要的SDK和工具

**为什么需要Android Studio？**
- Android Studio是Google官方的Android开发工具
- 它包含了编译APK所需的所有工具（JDK、SDK、Gradle等）
- 自动管理依赖和配置，使用简单

#### 2. 打开项目

1. 启动Android Studio
2. 选择 "File" -> "Open"
3. 选择项目文件夹：`c:\Users\YUAN\mylearing\treacn\apk000\ScreenRecordApp`
4. 等待Gradle同步完成（首次需要下载依赖，可能需要几分钟）

**什么是Gradle同步？**
- Gradle会自动下载项目需要的依赖库
- 配置编译环境
- 检查项目结构是否正确

#### 3. 连接手机

1. 在手机上开启"开发者选项"：
   - 进入"设置" -> "关于手机"
   - 连续点击"版本号"7次，直到提示"您已处于开发者模式"
   
2. 在"开发者选项"中开启"USB调试"：
   - 进入"设置" -> "系统和更新" -> "开发者选项"
   - 打开"USB调试"开关
   
3. 用USB数据线连接手机和电脑
4. 手机上会弹出"允许USB调试"提示，点击"允许"

**为什么需要USB调试？**
- USB调试允许电脑向手机安装应用
- 这是Android的安全机制，防止恶意软件偷偷安装

#### 4. 编译和安装

1. 在Android Studio顶部工具栏，选择你的手机设备
2. 点击绿色的"运行"按钮（▶️图标）
3. 等待编译完成（首次编译可能需要5-10分钟）
4. APK会自动安装到手机上

**编译过程在做什么？**
- 编译Java代码为字节码
- 打包资源文件（图片、布局等）
- 生成APK安装包
- 传输到手机并安装

### 方法二：使用命令行（需要安装JDK和Android SDK）

如果你已经安装了JDK和Android SDK，可以使用命令行编译：

```bash
# 进入项目目录
cd c:\Users\YUAN\mylearing\treacn\apk000\ScreenRecordApp
```

- 发布版本：用于正式发布，经过优化和混淆，体积较小

## 📖 使用说明

### 首次使用

1. 打开"熄屏录像"应用
2. 应用会请求以下权限，请全部授予：
   - **相机权限**：用于录制视频
   - **录音权限**：用于录制声音
   - **存储权限**：用于保存视频到相册

3. 权限授予后，界面会显示"准备就绪"

### 开始录像

1. 点击屏幕中央的红色圆形按钮
2. 按钮变为红色方形，表示正在录像
3. 计时器开始显示录像时长
4. 通知栏会显示"正在录像"通知

### 熄屏录像

1. 录像开始后，可以按电源键熄灭屏幕
2. 录像会在后台继续进行
3. 通知栏会持续显示"正在录像"通知
4. 通知无法滑动删除，确保录像不被意外停止

### 停止录像

1. 重新打开应用
2. 点击红色方形按钮
3. 视频会自动保存到相册
4. 界面显示"录像已保存"

### 查看视频

1. 打开手机"相册"应用
2. 进入"视频"分类
3. 找到"ScreenRecord"文件夹
4. 所有录制的视频都在这里

## 📁 视频保存位置

视频保存在以下路径：
```
内部存储/Movies/ScreenRecord/
```

文件命名格式：`VID_年月日_时分秒.mp4`
例如：`VID_20260216_193045.mp4`

## ⚠️ 注意事项

### 权限问题

如果应用无法启动录像，请检查：
1. 是否授予了相机权限
2. 是否授予了录音权限
3. 是否授予了存储权限
4. 是否在"设置" -> "应用管理" -> "熄屏录像"中手动授予了权限

### 存储空间

确保手机有足够的存储空间：
- 1分钟视频约占用50-100MB
- 建议至少预留1GB可用空间

### 电量消耗

持续录像会消耗较多电量：
- 建议连接充电器使用
- 录像时手机会发热，这是正常现象

### 系统限制

某些Android系统可能会限制后台应用：
- 如果录像意外停止，请检查电池优化设置
- 将"熄屏录像"加入电池优化白名单

## 🔍 故障排除

### 问题：无法打开相机

**解决方案：**
1. 检查相机权限是否授予
2. 检查是否有其他应用正在使用相机
3. 重启手机后再试

### 问题：录像自动停止

**解决方案：**
1. 检查存储空间是否充足
2. 检查电池优化设置
3. 确保通知权限已授予

### 问题：视频无法在相册中看到

**解决方案：**
1. 重启手机
2. 检查文件管理器中是否存在视频文件
3. 使用文件管理器打开视频

### 问题：无法安装APK

**解决方案：**
1. 检查USB调试是否开启
2. 检查USB连接模式是否为"文件传输"
3. 尝试更换USB数据线
4. 尝试更换USB接口

## 🛠️ 技术说明

### 为什么需要前台服务？

Android系统为了省电，会限制后台应用的运行。前台服务是一种特殊的服务，它会在通知栏显示通知，告诉用户应用正在后台工作。这样可以防止系统杀死应用，确保录像持续进行。

### 什么是唤醒锁（WakeLock）？

唤醒锁可以防止CPU进入休眠状态。即使屏幕熄灭，CPU也会保持运行，确保录像不中断。

### 为什么视频要保存到公共目录？

将视频保存到Movies公共目录的好处：
1. 用户可以在相册中直接查看
2. 卸载应用后视频不会丢失
3. 其他应用也可以访问这些视频
